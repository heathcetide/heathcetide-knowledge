#### RPM/TPM/QPM
限流里的 **RPM** 通常指 **Requests Per Minute**，也就是**每分钟请求数**（每分钟允许/实际处理的请求量）。

+ **例子**：限流配置 RPM=120 通常表示 **每分钟最多 120 次请求**（平均 2 次/秒）。
+ 常见一起出现的还有：
    - **RPS**：Requests Per Second（每秒请求数）
    - **TPM**：Tokens Per Minute（每分钟 token 数，常见于大模型接口）
    - **QPM**：Queries Per Minute（每分钟查询数，某些数据库/搜索服务会用）



#### 灌水模型
“灌水模型”不是一个特别严格的学术术语，更像是网络/圈内说法，一般指这类模型：

+ **输出很多，但信息密度很低**：话很多、重复、绕圈子、堆套话。
+ **看起来很会说，但不解决问题**：给一堆“正确但没用”的泛泛建议。
+ **喜欢扩写/凑字数**：把一句话能说明的内容写成一大段。
+ **回避关键结论**：不敢下判断，或者用模糊表述掩盖不确定。
