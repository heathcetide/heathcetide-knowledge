### **1. 缓存优化**
#### **1.1 防止缓存穿透**
当前使用了 Redis 缓存，但未处理可能的缓存穿透问题。如果查询一个不存在的用户名（比如恶意攻击者频繁查询），会不断打到数据库。可以通过以下方式优化
+ **将空值写入缓存**： 在 `getUserByUsername` 中，如果数据库中查询结果为 `null`，将一个占位值（如 `"null"`) 写入缓存，同时设置较短的过期时间。

```plain
java


复制代码
if (user == null) {
 logger.warn("User not found for username: {}. Adding placeholder to cache.", username);
 redisUtils.set(cacheKey, "null", 60); // 缓存空值 60 秒
 throw new CustomException("用户不存在");
}
```

+ **在读取缓存时忽略空值占位**
```plain
java


复制代码
if ("null".equals(cached)) {
 throw new CustomException("用户不存在");
}
```

---

#### **1.2 防止缓存雪崩**
当大量缓存同时过期时，可能引发缓存雪崩导致数据库压力激增。可以通过**随机过期时间**缓解
```plain
java


复制代码
// 写入缓存时，增加随机过期时间

```

---

#### **1.3 防止缓存击穿**
当一个缓存失效时，多个线程同时查询会并发访问数据库。可以通过**互斥锁（分布式锁）**解决
```plain
java

 cached = redisUtils.get(cacheKey);
 if (cached != null) {
 return SerializationUtils.clone((User) cached);
 }

 // 数据库查询和写入缓存逻辑
}
```

对于分布式环境，可以使用 Redis 的 `SETNX` 实现分布式锁。
