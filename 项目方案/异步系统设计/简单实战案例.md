# SpringBoot 异步实战：`@Async`用法
## 1. 第一步：开启异步支持
在你的**启动类**（比如 `CodeForgeApplication`）上加
```plain
@SpringBootApplication
@EnableAsync
public class CodeForgeApplication {
 public static void main(String[] args) {
 SpringApplication.run(CodeForgeApplication.class, args);
 }
}
```

`@EnableAsync` 是必须加的！它告诉 SpringBoot：“我要用异步了！”

## 2. 第二步：在方法上加 `@Async`
比如你有一个抓取数据的任务 `GrabArticleData`，你可以这样写
```plain
@Component
public class GrabArticleData {

 @Resource
 private ArticleService articleService;

 @Async
 public void grabSinglePage(int pageNum) {
 String json = "{ \"current\": " + pageNum + ", \"pageSize\": 20, \"sortField\": \"createTime\", \"sortOrder\": \"descend\", \"category\": \"文章\", \"tags\": [], \"reviewStatus\": 1 }";
 // 调用你的抓取方法
 grabArticleData(json);
 }

 public void grabArticleData(String json) {
 // 你的抓取逻辑（之前写的就可以直接拿来用）
 }
}
```

---

## 3. 第三步：调用时就是**异步启动了**
比如你想同时抓 15 页
```plain
@PostConstruct
public void executeTask() {
 for (int i = 1; i <= 15; i++) {
 grabSinglePage(i); // 直接异步调用！
 }
}
```

这样，**每一页数据的抓取就是一个独立线程**，同时并发执行，超级快！

---

# 注意点！
| 注意点 | 说明 |
| --- | --- |
| 方法必须是 `public` | `@Async`<br/> 修饰的方法必须是 `public`<br/> 的，否则不生效 |
| 不要自己内部调用自己 | 比如你在类里 `this.grabSinglePage()`<br/>，是无效的，要让 Spring去代理调用 |
| 返回值可以是 `void`<br/>，也可以是 `Future`<br/>、`CompletableFuture` | 如果你想拿到异步结果，就用 `Future` |
| 默认线程池有限（一般是CPU核数*2） | 如果要大批量并发，建议自定义线程池 |

# 扩展一下：如果你想拿异步返回结果？
可以这么写
```plain
@Async
public CompletableFuture<String> grabSinglePage(int pageNum) {
 String result = "第" + pageNum + "页数据抓取完成";
 return CompletableFuture.completedFuture(result);
}
```

然后调用时
```plain
CompletableFuture<String> future = grabSinglePage(1);
String result = future.get(); // 等待结果返回（可选）
```

---

# 总结一句话
用 `@Async`，就是让方法在**后台起一个线程**干活，不阻塞主流程！
