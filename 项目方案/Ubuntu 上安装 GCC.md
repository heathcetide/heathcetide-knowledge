## 📌 前提条件：你得有这几样
✔ 一台能运行 Ubuntu 的电脑（比如 18.04、20.04、22.04）
✔ 有管理员权限（就是能用 `sudo` 那种）
✔ 最重要：你想跑 Go 程序，系统却说“得先装个 GCC！”

---

## 🧐 为什么 Go 要用到 GCC？
Go 本身是“独立运行型”语言，用官方的 `go` 工具链就能编译，但有时候它会**调用 C 编译器（GCC）来搞定底层依赖**，比如
+ 用了 CGO（Go 调用 C 语言库）
+ 编译含 C 代码的 Go 库
+ 用的是 GCCGo 编译器（Go 的另一个版本，来自 GCC 家族）
+ 系统缺少 `build-essential` 导致 Go 构建过程出错

🔧 所以哪怕你是纯 Go 开发者，也最好让系统的“工具箱”有点料，**装上 GCC**，你跑 Go 代码才不会“跪”在中途。

### 2️⃣ 安装 GCC 和朋友们：构建世界的砖头瓦块
```bash
sudo apt install build-essential -y
```

🔍 `build-essential` 不止安装了 `gcc`，还顺手把这些也带上了
+ `g++`：C++ 编译器
+ `make`：构建神器
+ 头文件 & 库文件：没有它们，Go 构建过程可能直接罢工

### 4️⃣ 编译测试代码
```bash
nano hello.c
```

粘贴这点小东西进去
```c
#include <stdio.h>

int main() {
 printf("Hello, GCC!\n");
 return 0;
}
```

然后按下
+ `Ctrl+O` → 保存
+ `Enter` → 确认
+ `Ctrl+X` → 退出编辑器

接着
```bash
gcc hello.c -o hello
./hello
```

✅ 如果你看到 `Hello, GCC!`，说明它真的能干活，不是个摆设。

---

### 📦 安装特定版本的 GCC（比如你强烈想要 12 版）
```bash
sudo apt install gcc-12 g++-12
```

接着告诉系统“以后默认就用这个版本”
```bash
sudo update-alternatives --install /usr/bin/gcc gcc /usr/bin/gcc-12 100
sudo update-alternatives --install /usr/bin/g++ g++ /usr/bin/g++-12 100
```

⚙️ 如果你还想切换版本，可以运行
```bash
sudo update-alternatives --config gcc
```

---

### 🧹 卸载 GCC
```bash
sudo apt remove build-essential gcc g++
```
