微信小程序想用localhost但是出现了报错



在使用微信小程序开发的过程中，微信小程序是不允许使用localhost或者127.0.0.1进行操作的，这个时候如果要访问的话可以使用内网穿透，这里是使用正式的合理域名才可以



配置合法域名：

登录到 微信公众平台。

进入“开发” -> “开发设置”。

在“服务器域名”部分，添加你需要访问的域名到 request 合法域名列表中。

注意：域名需要经过 HTTPS 认证，并且需要添加 https:// 前缀



在 Taro 中使用 Taro.request 发起网络请求时，如果你尝试访问本地服务器（如 [http://localhost:8080](http://localhost:8080)），会遇到访问失败的问题。这是因为微信小程序和 H5 环境对网络请求有严格的同源策略限制。

解决方案

修改请求地址：

微信小程序不允许直接访问 localhost 或 127.0.0.1。需要将地址更改为真实的 IP 地址或者域名。

如果你的本地服务器运行在本机上，可以使用本机的 IP 地址来代替 localhost。

配置合法域名：

对于微信小程序，需要在微信公众平台上配置合法域名。

登录微信公众平台，进入“开发”->“开发设置”，在“服务器域名”部分添加你的本地服务器地址作为合法域名。

注意：对于本地开发环境，可以使用内网穿透工具（如 ngrok）将本地服务暴露到公网，并使用生成的公网 URL 作为合法域名。

使用内网穿透工具：

如果你的本地服务器运行在本机上，可以使用 ngrok 或类似工具将本地服务暴露到公网。

安装并启动 ngrok：

```plain
     ngrok http 8080
```

获取 ngrok 提供的 HTTPS 地址，并将其作为合法域名添加到微信公众平台。

修改代码：

将请求地址更改为实际的 IP 地址或 ngrok 提供的地址。

```plain
     async function requests({ url, method, data }: RequestParam): Promise<any> {
       const result = await Taro.request({
         url: "https://your-ngrok-address" + url, // 使用 ngrok 地址
         method,
         mode: "cors",
         data,
       });
       return result && result.data;
     }
```

H5 环境：

如果是在 H5 环境下运行，可以直接使用 localhost 或者 127.0.0.1。

但是需要注意跨域问题，确保你的后端服务器允许跨域请求。

示例代码

假设你使用 ngrok 并获取到了一个 HTTPS 地址 [https://your-ngrok-address](https://your-ngrok-address)，那么你的代码应该修改为：

```plain
async function requests({ url, method, data }: RequestParam): Promise<any> {
  const result = await Taro.request({
    url: "https://your-ngrok-address" + url, // 使用 ngrok 地址
    method,
    mode: "cors",
    data,
  });
  return result && result.data;
}

```

使用内网穿透工具：

使用像 ngrok 这样的工具，它可以将你的本地服务器暴露到公网。

安装并启动 ngrok：

获取 ngrok 提供的 HTTPS 地址，并在微信开发者工具中进行调试。

修改微信开发者工具设置：

在微信开发者工具中，可以通过设置来允许访问本地服务器。

在微信开发者工具中选择“详情”选项卡。

勾选“不校验合法域名”、“不校验HTTPS证书”、“不校验Content-Type”三个选项。

使用本机 IP 地址（例如 [http://192.168.1.2:8080](http://192.168.1.2:8080)）来访问本地服务器。
