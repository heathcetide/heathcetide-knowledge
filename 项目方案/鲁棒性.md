**鲁棒性（Robustness）** 是指系统在面对各种意料之外的情况、错误或异常输入时，仍然能够继续正常工作或至少保持合理行为的能力。简单来说，鲁棒性是一种系统应对意外情况的能力，以确保在不理想的条件下，系统依然可以稳定、安全地运行。

### 具体来说，鲁棒性包含以下几个方面：
1. **应对异常输入**：
    - 系统能够处理无效的、格式错误的或者超出预期范围的输入，而不会崩溃。例如，登录系统能够处理错误的用户名或密码，而不是因为输入错误而出现未捕获的异常。
2. **错误容忍**：
    - 当系统出现部分故障时，能保证其它部分正常工作，或者至少给出合理的错误信息。比如，如果数据库写入失败，系统可以提示用户重试或暂时不可用，而不是导致整个系统崩溃。
3. **性能在恶劣环境下的保持**：
    - 即使在负载增加、系统资源耗尽等情况下，系统也可以保持一定的性能和响应，而不是完全停滞或崩溃。例如，负载均衡机制可以让请求分散，以减少单一服务器的压力。
4. **持续运行能力**：
    - 面对某些硬件或软件错误，系统可以自动恢复或尽可能地保持服务。例如，容错机制能够在某个服务节点失败时，将服务转移到其他节点上。

### 鲁棒性与其他概念的区别
+ **鲁棒性 vs 健壮性**： “鲁棒性”和“健壮性”在某些情况下是同义词，但更多时候，**鲁棒性**偏向于应对异常和错误，而**健壮性**则强调整体设计的可靠性和抗干扰性。
+ **鲁棒性 vs 容错性**： **容错性** 是鲁棒性的一个子集，专门指系统在出现故障时如何继续提供服务，例如通过冗余设计来防止单点故障导致系统失效。

### 实现系统鲁棒性的常见策略
1. **输入验证**：
    - 验证用户输入的合法性是鲁棒性设计中的关键步骤。这样可以避免无效或恶意数据导致系统崩溃或行为异常。
2. **异常处理**：
    - 在代码中进行全面的异常处理，捕获系统运行中的各种异常，例如网络超时、数据库连接失败等，确保系统不会因为未捕获的异常而崩溃。
3. **容错机制**：
    - 在设计系统时，通过冗余、备份等方式防止单个组件的故障影响整个系统的运行。比如，数据冗余可以防止单点硬盘故障导致数据丢失。
4. **重试机制**：
    - 对于网络请求、数据库操作等，失败时可以进行一定次数的重试，从而提高系统应对瞬时故障的能力。
5. **限流与降级**：
    - 在流量过大时，系统可以通过限流或降级部分功能，保证核心功能的正常运行，而不是因为超负载导致系统完全不可用。

### 举个例子
假设你在一个电商网站上提交了订单，但在提交的过程中，支付服务出现了问题。鲁棒性的设计应该确保：

+ 订单不会因为支付问题而丢失，可以保存订单状态并让用户稍后完成支付。
+ 系统应显示友好的错误提示，告知用户支付系统暂时不可用，而不是显示技术错误信息或直接崩溃。
+ 支付失败后，可以进行有限次数的自动重试，或者提供其他支付选项给用户。

总的来说，**鲁棒性**是软件系统的重要属性，能有效提升系统面对不确定因素时的稳定性和用户体验。在设计软件时，提升系统鲁棒性有助于减少系统故障对用户的影响，提升产品的可靠性和竞争力。

    /**
     * 执行带鲁棒性的操作。
     *

     * 获取鲁棒性处理的当前状态。
     *
     * @return 状态信息
     */
    String getStatus();

     * 清理或重置鲁棒性处理状态。
     */
    void reset();
}

/**
 * 具体业务逻辑的接口。

@FunctionalInterface
public interface RobustAction<T> {
    T run() throws Exception;
}

/**
 * 降级逻辑的接口。

@FunctionalInterface
public interface RobustFallback<T> {
    T fallback(Exception e);
}

#### **2. 重试策略实现**
实现带重试能力的鲁棒性处理器。

```plain
import java.util.concurrent.TimeUnit;

public class RetryRobustnessHandler<T> implements RobustnessHandler<T> {

    private int maxRetries;  // 最大重试次数
    private long retryInterval;  // 重试间隔时间（毫秒）
    private RobustFallback<T> fallback;  // 降级逻辑

    public RetryRobustnessHandler(int maxRetries, long retryInterval) {
        this.maxRetries = maxRetries;
        this.retryInterval = retryInterval;
    }

    @Override
    public T execute(RobustAction<T> action) throws Exception {
        int attempt = 0;
        while (attempt < maxRetries) {
            try {
                return action.run(); // 尝试执行业务逻辑
            } catch (Exception e) {
                attempt++;
                if (attempt >= maxRetries) {
                    if (fallback != null) {
                        return fallback.fallback(e); // 执行降级逻辑
                    }
                    throw e; // 抛出异常
                }
                TimeUnit.MILLISECONDS.sleep(retryInterval); // 等待重试
            }
        }
        return null; // 不应该到达此处
    }

    @Override
    public void setFallback(RobustFallback<T> fallback) {
        this.fallback = fallback;
    }

    @Override
    public String getStatus() {
        return "RetryHandler: maxRetries=" + maxRetries + ", retryInterval=" + retryInterval + "ms";
    }

    @Override
    public void reset() {
        // 重试策略无需特殊状态重置
    }
}
```

#### **3. 熔断策略实现**
实现带熔断能力的鲁棒性处理器。

```plain
import java.util.concurrent.atomic.AtomicInteger;

public class CircuitBreakerRobustnessHandler<T> implements RobustnessHandler<T> {

    private int failureThreshold; // 熔断触发的失败次数
    private long openStateDuration; // 熔断器打开的持续时间（毫秒）
    private AtomicInteger failureCount = new AtomicInteger(0);
    private long openStartTime = 0;
    private RobustFallback<T> fallback;

    public CircuitBreakerRobustnessHandler(int failureThreshold, long openStateDuration) {
        this.failureThreshold = failureThreshold;
        this.openStateDuration = openStateDuration;
    }

    @Override
    public T execute(RobustAction<T> action) throws Exception {
        // 检查熔断器状态
        if (isCircuitOpen()) {
            if (fallback != null) {
                return fallback.fallback(new RuntimeException("CircuitBreaker is OPEN"));
            }
            throw new RuntimeException("CircuitBreaker is OPEN");
        }

        try {
            T result = action.run(); // 执行业务逻辑
            failureCount.set(0); // 重置失败计数
            return result;
        } catch (Exception e) {
            if (failureCount.incrementAndGet() >= failureThreshold) {
                openStartTime = System.currentTimeMillis(); // 打开熔断器
            }
            throw e;
        }
    }

    @Override
    public void setFallback(RobustFallback<T> fallback) {
        this.fallback = fallback;
    }

    @Override
    public String getStatus() {
        return "CircuitBreaker: state=" + (isCircuitOpen() ? "OPEN" : "CLOSED") +
               ", failures=" + failureCount.get();
    }

    @Override
    public void reset() {
        failureCount.set(0);
        openStartTime = 0;
    }

    private boolean isCircuitOpen() {
        if (failureCount.get() < failureThreshold) {
            return false; // 未达到熔断阈值
        }
        return System.currentTimeMillis() - openStartTime < openStateDuration; // 是否仍处于打开状态
    }
}
```

### **2. 重试策略实现**
针对瞬时错误（如网络波动）实现的重试逻辑。

```java
import java.util.concurrent.TimeUnit;

public class RetryHandler<T> implements RobustnessHandler<T> {

    private int maxRetries;          // 最大重试次数
    private long retryIntervalMs;    // 重试间隔时间
    private RobustFallback<T> fallback;

    public RetryHandler(int maxRetries, long retryIntervalMs) {
        this.maxRetries = maxRetries;
        this.retryIntervalMs = retryIntervalMs;
    }

    @Override
    public T execute(RobustAction<T> action) throws Exception {
        int attempts = 0;
        while (attempts <= maxRetries) {
            try {
                return action.run();
            } catch (Exception e) {
                attempts++;
                if (attempts > maxRetries) {
                    if (fallback != null) {
                        return fallback.fallback(e); // 执行降级逻辑
                    }
                    throw e; // 超过重试次数后抛出异常
                }
                TimeUnit.MILLISECONDS.sleep(retryIntervalMs);
            }
        }
        return null; // 不应该到达这里
    }

    @Override
    public void setFallback(RobustFallback<T> fallback) {
        this.fallback = fallback;
    }

    @Override
    public String getStatus() {
        return "RetryHandler: maxRetries=" + maxRetries + ", retryIntervalMs=" + retryIntervalMs;
    }

    @Override
    public void reset() {
        // 重试逻辑无需要重置状态
    }
}
```

### **3. 熔断策略实现**
针对连续失败导致的服务不可用，提供熔断机制。

```java
import java.util.concurrent.atomic.AtomicInteger;

public class CircuitBreakerHandler<T> implements RobustnessHandler<T> {

    private int failureThreshold;    // 失败次数阈值
    private long openDurationMs;     // 熔断器打开的持续时间
    private AtomicInteger failureCount = new AtomicInteger(0);
    private long openTimestamp = 0;  // 熔断器打开时间戳
    private RobustFallback<T> fallback;

    public CircuitBreakerHandler(int failureThreshold, long openDurationMs) {
        this.failureThreshold = failureThreshold;
        this.openDurationMs = openDurationMs;
    }

    @Override
    public T execute(RobustAction<T> action) throws Exception {
        if (isCircuitOpen()) {
            if (fallback != null) {
                return fallback.fallback(new RuntimeException("CircuitBreaker is OPEN"));
            }
            throw new RuntimeException("CircuitBreaker is OPEN");
        }

        try {
            T result = action.run();
            failureCount.set(0); // 成功时重置失败计数
            return result;
        } catch (Exception e) {
            if (failureCount.incrementAndGet() >= failureThreshold) {
                openTimestamp = System.currentTimeMillis(); // 打开熔断器
            }
            throw e;
        }
    }

    @Override
    public void setFallback(RobustFallback<T> fallback) {
        this.fallback = fallback;
    }

    @Override
    public String getStatus() {
        return "CircuitBreakerHandler: state=" + (isCircuitOpen() ? "OPEN" : "CLOSED") +
        ", failures=" + failureCount.get();
    }

    @Override
    public void reset() {
        failureCount.set(0);
        openTimestamp = 0;
    }

    private boolean isCircuitOpen() {
        if (failureCount.get() < failureThreshold) {
            return false;
        }
        return System.currentTimeMillis() - openTimestamp < openDurationMs;
    }
}
```

### **4. 策略组合器**
支持多策略组合（如重试+熔断+降级）。

```java
import java.util.ArrayList;
import java.util.List;

public class CompositeHandler<T> implements RobustnessHandler<T> {

    private List<RobustnessHandler<T>> handlers = new ArrayList<>();

    public void addHandler(RobustnessHandler<T> handler) {
        handlers.add(handler);
    }

    @Override
    public T execute(RobustAction<T> action) throws Exception {
        for (RobustnessHandler<T> handler : handlers) {
            try {
                return handler.execute(action);
            } catch (Exception e) {
                // 如果当前策略失败，尝试下一个
            }
        }
        throw new RuntimeException("All strategies failed");
    }

    @Override
    public void setFallback(RobustFallback<T> fallback) {
        handlers.forEach(handler -> handler.setFallback(fallback));
    }

    @Override
    public String getStatus() {
        StringBuilder status = new StringBuilder();
        for (RobustnessHandler<T> handler : handlers) {
            status.append(handler.getStatus()).append("\n");
        }
        return status.toString();
    }

    @Override
    public void reset() {
        handlers.forEach(RobustnessHandler::reset);
    }
}
```

import java.util.HashMap;

        return (RobustnessHandler<T>) handlers.get(key);

    public static void resetAll() {
        handlers.values().forEach(RobustnessHandler::reset);
    }
}
