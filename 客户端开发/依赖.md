### 1. **防抖（Debounce）**
防抖技术确保在事件被触发后，一定时间内只执行一次操作。例如，用户输入时不会每输入一个字符就触发请求，而是在用户停止输入一段时间后才执行。

**应用场景**：搜索框输入、按钮点击等。

**实现**：

```plain
// 防抖（debounce）封装
extension DebounceExtension on Function {
  void Function() debounce([int milliseconds = 500]) {
    Timer? _debounceTimer;
    return () {
      if (_debounceTimer?.isActive ?? false) _debounceTimer?.cancel();
      _debounceTimer = Timer(Duration(milliseconds: milliseconds), this);
    };
  }
}
```

### 2. **节流（Throttle）**
节流技术限制事件的触发频率，确保在规定时间内，事件只会执行一次。例如，滚动页面时频繁触发事件，但在一定时间内只允许触发一次。

**应用场景**：滚动监听、窗口大小调整等。

**实现**：

```plain
// 节流（throttle）封装
extension ThrottleExtension on Function {
  void Function() throttle([int milliseconds = 500]) {
    bool _isAllowed = true;
    Timer? _throttleTimer;
    return () {
      if (!_isAllowed) return;
      _isAllowed = false;
      this();
      _throttleTimer?.cancel();
      _throttleTimer = Timer(Duration(milliseconds: milliseconds), () {
        _isAllowed = true;
      });
    };
  }
}
```

### 4. **批处理（Batching）**
批处理技术将多个事件合并成一个操作，避免多次重复执行。这有助于减少不必要的渲染和计算。

**应用场景**：大规模数据操作、DOM更新、网络请求批量处理等。

**实现**：

```plain
List<Function> batchOperations = [];

void addToBatch(Function operation) {
  batchOperations.add(operation);
}

void executeBatch() {
  for (var operation in batchOperations) {
    operation();
  }
  batchOperations.clear();
}
```

**应用场景**：图片、视频、列表数据等。

**实现**：

```plain
// 延迟加载图片示例
Image.asset('assets/images/your_image.png', loadingBuilder: (BuildContext context, Widget child, ImageChunkEvent? loadingProgress) {
  if (loadingProgress == null) {
    return child;
  } else {
    return Center(
      child: CircularProgressIndicator(
        value: loadingProgress.expectedTotalBytes != null
            ? loadingProgress.cumulativeBytesLoaded /
                (loadingProgress.expectedTotalBytes ?? 1)

      ),
    );
  }
});
```

### 31. **异步 UI 渲染（Async UI Rendering）**
在 Flutter 中，使用 `FutureBuilder` 和 `StreamBuilder` 可以处理异步数据，并在数据加载完成后更新 UI。这避免了同步操作阻塞 UI 渲染。

**应用场景**：需要从网络、数据库或本地存储加载数据的应用。

**实现**：

```plain
dart


复制编辑
// 使用 FutureBuilder 来异步加载数据
FutureBuilder<List<String>>(
  future: fetchData(), // 获取异步数据
  builder: (context, snapshot) {
    if (snapshot.connectionState == ConnectionState.waiting) {
      return CircularProgressIndicator();
    } else if (snapshot.hasError) {
      return Text('Error: ${snapshot.error}');
    } else {
      return ListView.builder(
        itemCount: snapshot.data!.length,
        itemBuilder: (context, index) {
          return Text(snapshot.data![index]);
        },
      );
    }
  },
);
```
