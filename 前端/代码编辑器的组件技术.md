在 GitHub 上有许多可以嵌入到 HTML 页面中的代码编辑器组件。这些组件通常用于创建在线代码编辑器、IDE、代码演示等。以下是一些流行的代码编辑器组件和技术：

1. CodeMirror

CodeMirror 是一个非常强大的、可扩展的代码编辑器库，适用于 Web 应用程序。它支持多种编程语言，并且高度可定制。

GitHub 仓库: codemirror/CodeMirror

示例代码:

```java
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>CodeMirror Example</title>
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.62.0/codemirror.min.css">
    <script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.62.0/codemirror.min.js"></script>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/codemirror/5.62.0/mode/javascript/javascript.min.js"></script>
</head>
<body>
    <textarea id="code" name="code">
        function helloWorld() {
            console.log("Hello, world!");
        }
    </textarea>
    <script>
        var editor = CodeMirror.fromTextArea(document.getElementById("code"), {
            lineNumbers: true,
            mode: "javascript",
            theme: "default"
        });
    </script>
</body>
</html>
```

2. Monaco Editor

Monaco Editor 是 Visual Studio Code 的核心编辑器，由 Microsoft 开发。它功能强大，支持多种语言，并且具有丰富的 API。

GitHub 仓库: microsoft/monaco-editor

示例代码:

```java
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Monaco Editor Example</title>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/monaco-editor/0.33.0/min/vs/loader.min.js"></script>
</head>
<body>
    <div id="container" style="width:800px;height:600px;border:1px solid grey"></div>
    <script>
        require.config({ paths: { 'vs': 'https://cdnjs.cloudflare.com/ajax/libs/monaco-editor/0.33.0/min/vs' }});
        require(['vs/editor/editor.main'], function() {
            var editor = monaco.editor.create(document.getElementById('container'), {
                value: [
                    'function helloWorld() {',
                    '\tconsole.log("Hello, world!");',
                    '}'
                ].join('\n'),
                language: 'javascript'
            });
        });
    </script>
</body>
</html>
```

3. Ace Editor

Ace Editor 是一个嵌入式代码编辑器，最初是 Cloud9 IDE 的一部分。它支持多种编程语言，并且具有良好的性能和可定制性。

GitHub 仓库: ajaxorg/ace

示例代码:

```java
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Ace Editor Example</title>
    <script src="https://cdnjs.cloudflare.com/ajax/libs/ace/1.4.12/ace.js"></script>
</head>
<body>
    <div id="editor" style="height: 500px; width: 800px; border: 1px solid black;"></div>
    <script>
        var editor = ace.edit("editor");
        editor.setTheme("ace/theme/monokai");
        editor.session.setMode("ace/mode/javascript");
        editor.setValue("function helloWorld() {\n\tconsole.log('Hello, world!');\n}");
    </script>
</body>
</html>
```

4. Quill

虽然 Quill 主要是一个富文本编辑器，但它也可以用于代码编辑。如果你需要一个更简单的编辑器，Quill 可能是一个不错的选择。

GitHub 仓库: quilljs/quill

示例代码:

```java
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Quill Example</title>
    <link href="https://cdn.quilljs.com/1.3.6/quill.snow.css" rel="stylesheet">
    <script src="https://cdn.quilljs.com/1.3.6/quill.min.js"></script>
</head>
<body>
    <div id="editor" style="height: 300px;"></div>
    <script>
        var quill = new Quill('#editor', {
            theme: 'snow'
        });
        quill.clipboard.addMatcher(Node.ELEMENT_NODE, function(node, delta) {
            if (node.tagName === 'CODE') {
                return new Delta().insert(node.textContent, { 'code-block': true });
            }
            return delta;
        });
        quill.setContents([
            { insert: 'function helloWorld() {\n' },
            { insert: '  console.log("Hello, world!");\n', attributes: { 'code-block': true } },
            { insert: '}\n', attributes: { 'code-block': true } }
        ]);
    </script>
</body>
</html>
```



总结

以上是一些常用的代码编辑器组件，它们都可以嵌入到 HTML 页面中。根据你的需求选择合适的编辑器：

CodeMirror: 功能丰富，易于集成。

Monaco Editor: 功能强大，适合需要高级功能的场景。

Ace Editor: 性能优秀，支持多种语言。

Quill: 富文本编辑器，适合简单代码编辑需求。
