**2 修改配置文件**  
 配置文件主要是两个一个 con目录下的application.properties 和 bin目录下的startup.cmd  
** 2.1)application.properties 文件**  
**2.1.1)将nacos-mysql.sql 文件里的sql脚本执行到本地数据中**

CREATE DATABASE IF NOT EXISTS nacos_config DEFAULT CHARACTER SET = utf8mb4;

**执行后的结果**

**2.2)startup.cmd 文件**  
startup.cmd 是nacos在win系统下的启动文件，主要是改nacos的启动模式，改成单机版  
<font style="color:rgb(77, 77, 77);">nacos 启动模式有两种： </font><font style="color:rgb(199, 37, 78);background-color:rgb(249, 242, 244);">cluster</font><font style="color:rgb(77, 77, 77);"> 集群模式 和</font><font style="color:rgb(199, 37, 78);background-color:rgb(249, 242, 244);"> standalone</font><font style="color:rgb(77, 77, 77);"> 单机模式。</font>  


<!-- 这是一张图片，ocr 内容为： -->

**3 启动nacos**  
**3.1)进入到nacos启动命令的目录**  
cd D:\java\code-application\nacos\bin  
执行启动命令 startup.cmd  


<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2022/png/22822197/1661953287650-e6b589e6-20f2-4171-9932-a334f9647d8b.png?x-oss-process=image%2Fformat%2Cwebp)

  
或者直点进启动目录下，双击启动命令  


<!-- 这是一张图片，ocr 内容为： -->
![](https://cdn.nlark.com/yuque/0/2022/png/22822197/1661953394871-51f808d9-24f1-47c6-987e-a66f439feb27.png?x-oss-process=image%2Fformat%2Cwebp)

  
  
没有报错,并看到successfully in stand alone mode 则表示启动成功
