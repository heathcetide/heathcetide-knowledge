# 2 基于Feign实现Http接口调用
  
**1)场景需求**  
一般只有在微服务的项目中，特别是SpringCloud项目中， 我们会使用Feign实现微服务的调用。但是我们能不能不是微服务的项目，普通的SpringBoot项目中，在集成外系统的时候，实现Http请求方外系统接口呢？答案是可以的。  
  
**2)实战**  
需求场景是，  
1,外系统提供url，我们请求去获取token然后再去调这个系统的接口  
2,请求的时候需要携带token，这个需要在请求头里面，将userName和password组成成请求头里的token  
通过上面分析， 我们可以得出， 请求外系统的接口，需要先获取请求的token， 这需要：请求这个token的url，userName，passWord这些参数  
  
**2.1)项目所需Feign的依赖**

```plain

<!--SpringCloud openfeign的依赖，版本在定义SpringBoot的父工程中定义 -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>
    

<!--SpringCloud ribbon负载均衡依赖， 在微服务中用得上，集成外系统用不上 -->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-netflix-ribbon</artifactId>
</dependency>
```

### 2.2)定义请求这个token的Feign接口定义
```plain
@FeignClient(name = "auth-server-start" ,url = "${ikea.p2l.host}" , path = "${ikea.auth-ser.path}",configuration = P2ITokenFeignConf9iguration.class)
public interface P2ITokenFeign {

    @PostMapping("/oauth/token")
    String getP2IToken(@RequestParam("grant_type") String grant_type,
                       @RequestParam("username") String username,
                       @RequestParam("password") String password,
                       @RequestParam("refresh_token") String refresh_token);
}

```

**@FeignClient注解**

**name：**调用外系统的服务的服务名，可以自己定义，  例如本案例中的，auth-server-start，在微服务中就是微服务的服务名， 是注册在注册中心的服务名，调用的时候可以不用指定url；

**url：**调用外系统的url**，**不是微服务调用的时候需要指定， 微服务调用则不需要；

**path**：调用外系统或者微服务的path，或者根据请求的接口路径自定义；

**configuration：**加在Spring的Bean，根据需要自己配置， 例如：需要在请求头里加token、或者设置成https                                  等，这个根据需要配置



**value:**



<font style="color:#722ED1;">案例中的参数以参数的形式配置在配置文件中，如下：</font>

${ikea.p2l.host}：[https://dev-p2l.livat.cn](https://dev-p2l.livat.cn)

${ikea.auth-ser.path}：auth-ser

```plain
ikea:
  p2l:
    host: https://dev-p2l.livat.cn
  auth-ser:
    username: mdm
    password: KOhkJjAmMpVJmyDb
    grant_type: client_credentials
    request_token: Basic cDJsLXdlYjo3MG9QenpycHlEUVhBOUxE
    path: auth-ser
```

**P2ITokenFeignConf9iguration**以SpringBoot加载Bean的形式，将生成的请求token设置到请求头中， 主要是Feign的拦截器<font style="color:rgb(0, 0, 0);">RequestInterceptor来实现的</font>  
${ikea.auth-ser.username}：mdm  
${ikea.auth-ser.password}：KOhkJjAmMpVJmyDb  


<font style="color:rgb(38, 38, 38);background-color:rgb(245, 245, 245);">  
</font>

```plain
public class P2ITokenFeignConfiguration {

    @Value("${ikea.auth-ser.username}")
    private String username;

    @Value("${ikea.auth-ser.password}")
    private String password;

    @Bean
    public RequestInterceptor getInterceptor(){
        RequestInterceptor requestInterceptor = (requestTemplate) ->{
            String token = ApiConstant.TOKEN_PREFIX_BASIC + " " + Base64.getUrlEncoder().encodeToString((username + ":" + password).getBytes());
            requestTemplate.header(ApiConstant.TOKEN_PREFIX_HEADER_NAME,token);
        };
        return requestInterceptor;
    }
}
```

### <font style="color:#000000;">2.3)最终实现Http请求</font>
最终有Feign实现Http请求，最终执行http请求的url为：

@FeignClient注解上的 url+path，请求头设置请求的token，再加上接口的路径去请求外系统的接口。在SpringBoot的启动类上加上<font style="color:#9e880d;">@EnableFeignClients， 然后将</font>P2ITokenFeign注入到业务类中就可以调用getP2IToken这个方法， 由Feign去执行Http请求。
