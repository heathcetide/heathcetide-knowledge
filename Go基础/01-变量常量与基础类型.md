# 01 · 变量、常量与基础类型

---

## 面试题

### Q1. `=` 和 `:=` 有什么区别？

| | `=` | `:=` |
| --- | --- | --- |
| 含义 | 赋值 | 短变量声明 + 推断类型并赋值 |
| 要求 | 变量必须已声明 | 至少有一个新变量 |
| 作用域 | 给已有变量赋值 | 在当前块声明 |

```go
var a int
a = 1          // 赋值
b := 2         // 声明并赋值
a, c := 3, 4   // a 赋值，c 新声明（至少有一个新名字）
```

`:=` 不能用在函数外（包级只能 `var`/`const`）。

---

### Q2. 局部变量和全局变量的缺省值（零值）是什么？

Go **没有未初始化垃圾值**：声明后即零值。

| 类型 | 零值 |
| --- | --- |
| 数值 | 0 |
| bool | false |
| string | `""` |
| pointer / slice / map / chan / func / interface | nil |
| struct | 各字段零值 |

局部、包级变量规则相同，都是零值。

---

### Q3. 有类型常量 vs 无类型常量？

- **无类型常量**：`const x = 1`，精度可很高，可隐式用到需要的上下文（未溢出时）  
- **有类型常量**：`const y int32 = 1`，类型固定，赋值受类型规则约束  

无类型常量是 Go「常量算术更灵活」的关键。

---

### Q4. rune 是什么？rune 和 byte 区别？

| | byte | rune |
| --- | --- | --- |
| 定义 | `byte` 是 `uint8` 别名 | `rune` 是 `int32` 别名 |
| 含义 | 一个字节 | 一个 Unicode **码点**（大致一个字符） |
| 字符串 | `len(s)` 是字节数 | `for _, r := range s` 按 rune |

中文常占 3 个 UTF-8 字节、1 个 rune。处理「字符」用 rune；处理原始字节用 byte。

---

### Q5. 如何表示枚举 enums？

Go **无 enum 关键字**。常见：

```go
type Status int
const (
    StatusOK Status = iota
    StatusFail
    StatusPending
)
```

也可用字符串常量。需要 bo 校验时自己写方法。

---

### Q6. 空 `struct{}` 的用途？

`struct{}` **大小为 0**，不占内存（或可忽略）。用途：

1. `map[K]struct{}` 实现 **set**（只关心 key）  
2. 信号 channel：`chan struct{}` 只传递「发生了」  
3. 嵌入占位、方法集挂载  

---

### Q7. Go 支持默认参数或可选参数吗？

**不支持。** 设计选择：避免歧义。可选参数用：

- 函数选项模式（Functional Options）  
- 传入 struct 配置  
- 变参 `...T`（不是默认值，是可变数量）  

---

### Q8. 如何交换两个变量？

```go
a, b = b, a
```

支持多值赋值，无需临时变量（编译器处理）。

---

### Q9. `%v` 和 `%+v` 区别？

打印结构体时：

- `%v`：字段值  
- `%+v`：带**字段名**  
- `%#v`：Go 语法表示  

字符串本身两者通常差不多；问「打印」时常指 struct。

---

### Q10. 字面量与组合字面量？

- **字面量：** `42`、`"hi"`、`true`  
- **组合字面量：** 构造复合类型，如 `Person{Name: "a"}`、`[]int{1,2}`、`map[string]int{"x":1}`  

---

### Q11. 类型的值可以修改吗？

- 变量可以改：`var x int; x = 2`  
- **常量不可改**  
- 通过指针可改指向的值  
- map/slice 头是值类型，但可改底层数据（见切片/map 章）
