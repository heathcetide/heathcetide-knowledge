# 09 · 着色器入门（Shader）

---

## 面试 / 自测题

### Q1. Godot 里常见 shader_type？

| 类型 | 用途 |
| --- | --- |
| `canvas_item` | 2D 精灵/UI |
| `spatial` | 3D |
| `particles` | 粒子 |

2D 游戏主要写 `canvas_item`。

---

### Q2. 最小 canvas_item 长什么样？

```glsl
shader_type canvas_item;

void fragment() {
    vec4 c = texture(TEXTURE, UV);
    c.rgb *= vec3(1.0, 0.8, 0.8); // 轻微染色
    COLOR = c;
}
```

挂到 `Sprite2D` / `ColorRect` 的 Material → ShaderMaterial。

---

### Q3. 屏幕特效（热浪、闪白）怎么做？

常见管线：

1. `BackBufferCopy` 拷屏  
2. 全屏 `ColorRect` + shader 采 `hint_screen_texture`  
3. 用 uniform 控制强度，逻辑里淡入淡出  

**Compatibility 限制**：

- 片段着色器里避免某些非法写法（如中途 `return` 曾导致整 shader 失败 → 白屏）  
- 能力弱于 Forward+，效果要克制  

---

### Q4. uniform 与脚本如何联动？

```glsl
uniform float strength : hint_range(0.0, 1.0) = 0.0;
```

```gdscript
material.set_shader_parameter("strength", 0.5)
```

---

### Q5. 采样 SCREEN_UV 要注意什么？

- UV 越界会采样到边缘脏数据 → `clamp`  
- 强度太大导致「糊成扭曲」——先小后大  
- 全屏特效每帧采屏，低端机贵，无双结束后一定关 `visible`  

---

### Q6. 什么时候不该用 shader？

- 简单闪白：调 `modulate` / Tween 就够  
- 帧动画火焰：精灵表往往更可控  
- 团队无人能维护的「炫技 shader」上线风险高  

---

## 易错点

- Shader 编译失败时 Compatibility 可能表现为粉红/白色方块。  
- `render_mode unshaded` 与光照预期不符。  
- 把编辑器预览当导出结果——真机后端不同效果不同。
