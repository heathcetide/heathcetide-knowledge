# 10 · 音频、对象池与特效

---

## 面试 / 自测题

### Q1. 音频节点怎么选？

| 节点 | 用途 |
| --- | --- |
| `AudioStreamPlayer` | 非空间（UI、BGM） |
| `AudioStreamPlayer2D` | 2D 衰减 |
| `AudioStreamPlayer3D` | 3D |

BGM 常用 Autoload 单例持有一个 Player，切场景不中断。

---

### Q2. 为什么要对象池？

频繁 `instantiate` + `queue_free`（子弹、飘字、命中特效）会造成卡顿与 GC 压力。

池化：

1. 预创建 N 个隐藏实例  
2. 取出 → 重置状态 → 显示  
3. 结束 → 隐藏并归还，而不是销毁  

---

### Q3. 特效场景怎么组织？

- 独立 `.tscn`：命中、爆炸、Buff 环  
- 播完动画 `animation_finished` → 回收/释放  
- 统一由 `Global.add_SpecialEffect(...)` 工厂创建，便于换皮与统计  

---

### Q4. 音效叠太多怎么办？

- 限制同名音效并发数  
- 优先级：UI < 攻击 < 重要语音  
- 总线（Bus）分组：BGM / SFX / Voice，好做设置里的分路音量  

---

### Q5. 资源流式加载？

`ResourceLoader.load_threaded_request` 可在加载屏异步载关卡。  
首次 `load()` 大场景会卡主线程——Boss 关、大地图要注意。

---

## 易错点

- 切场景后 BGM 节点被释放 → BGM 应在 Autoload。  
- 池对象未重置 `velocity`/计时器 → 「第二次发射行为诡异」。  
- Web 音频需用户手势后才能播放（浏览器策略）。
