# 06 · 物理与碰撞（2D）

---

## 面试 / 自测题

### Q1. CharacterBody2D、RigidBody2D、StaticBody2D、Area2D 怎么选？

| 类型 | 用途 |
| --- | --- |
| `CharacterBody2D` | 玩家/怪物：自己写移动，用 `move_and_slide` |
| `RigidBody2D` | 引擎积分：箱子、布娃娃 |
| `StaticBody2D` | 地面、墙 |
| `AnimatableBody2D` | 移动平台（运动学带动） |
| `Area2D` | 触发器、受击盒、拾取 |

横版动作游戏主角几乎总是 **CharacterBody2D**。

---

### Q2. `move_and_slide` 核心注意点？

```gdscript
velocity.x = input * speed
if not is_on_floor():
    velocity.y += gravity * delta
move_and_slide()
```

- 改的是 `velocity`，再调用 `move_and_slide`  
- 上下坡、贴墙摩擦与 `floor_max_angle`、`motion_mode` 有关  
- 碰撞后 `get_slide_collision_count()` 可取详情  

Godot 4 不再像 Godot 3 那样 `move_and_slide(velocity)` 传参为主流写法。

---

### Q3. 碰撞层（layer）和掩码（mask）？

- **layer**：我是谁（自己在哪些层）  
- **mask**：我撞谁（检测哪些层）  

二者位运算匹配才产生碰撞/重叠。

项目应用：玩家、敌人、子弹、地形、触发器分开放，避免「子弹撞到自己的受击盒」之类问题。

---

### Q4. 受击盒 / 攻击盒常见结构？

- 角色根：`CharacterBody2D`  
- 子 `Area2D`：`HitBox`（打别人） / `HurtBox`（被打）  
- 用 `area_entered` 信号处理伤害  
- 短暂无敌：计时器或状态机忽略 HurtBox  

保持 **HurtBox 与物理身体分离**，调数值不破坏移动碰撞。

---

### Q5. 射线检测怎么用？

```gdscript
var space = get_world_2d().direct_space_state
var query = PhysicsRayQueryParameters2D.create(from, to)
query.collision_mask = mask
var result = space.intersect_ray(query)
```

用于贴墙检测、瞄准、地面探测、AI 视线。

## 易错点

- Area 的 `monitoring` / `monitorable` 没开。  
- 缩放为负的节点导致碰撞怪异。  
- 在 `_process` 里做物理位移 → 抖动；改物理帧。  
- 父节点缩放影响碰撞形状，调试时看 Remote 变换。
