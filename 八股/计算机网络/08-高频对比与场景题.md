## 对比速记

| 对比 | 一句话 |
| --- | --- |
| TCP vs UDP | 可靠有连接 vs 轻快低延迟 |
| Reno vs CUBIC vs BBR | 丢包经典 / 丢包立方曲线 / 带宽时延模型 |
| 流量控制 vs 拥塞控制 | 怕接收方撑死 vs 怕网络堵死 |
| HTTP/2 流 vs TCP | H2 多路复用；TCP 丢包仍可能堵整连接 |
| H2 vs QUIC/H3 | TCP+TLS vs UDP 上可靠多路+连接迁移 |
| 超时重传 vs 快重传 | RTO vs 3 DupACK |
| TIME_WAIT vs CLOSE_WAIT | 主动方 2MSL vs 被动方未 close |
| 限流 vs 熔断 vs 降级 | 挡流量 / 快失败 / 兜底 |
| gRPC vs REST | H2+Protobuf vs HTTP+JSON |
| 正向代理 vs 反向代理 | 代理客户端 vs 代理服务端 |
| 四层 LB vs 七层 LB | IP/端口转发 vs 认 HTTP 内容 |
| 强缓存 vs 协商缓存 | 不发请求 vs 304 校验 |
| 301 vs 302 | 永久 vs 临时（SEO/方法保持看 307/308） |
| Cookie vs Session vs Token | 浏览器存 / 服务端存 / 常无状态 JWT |
| SIP vs RTP | 信令 vs 媒体 |
| WebSocket vs WebRTC | 信令/事件合适 vs 实时媒体栈 |
| WebSocket vs SSE | 全双工 vs 服务端单向流 |
| STUN vs TURN | 发现地址打洞 vs 中继保底 |
| XSS vs CSRF | 注入脚本 vs 借 Cookie 发请求 |
| 401 vs 403 / 502 vs 504 | 认证权限 / 上游坏与上游超时 |
| DoH/DoT vs HTTPDNS | 加密系统DNS vs App 自解析 |
| 对称加密 vs 非对称 | 快保会话 vs 慢做密钥/身份 |

## 场景题速答

### Q1. 接口偶发超时，怎么系统化排查？

1. 分清客户端超时 / 网关超时 / 服务超时哪个先到  
2. 看是否 DNS、建连、TLS、还是业务耗时  
3. 下游依赖、线程池、连接池、GC、慢查  
4. 抓包看重传、RST、零窗口  
5. 对齐超时链路：不能下游 5s、上游 1s（见 [[12-gRPC与网关治理]]）

---

### Q2. 为什么内网 ping 通但业务不通？

ping 只说明 ICMP；业务要 TCP 端口、安全组、TLS、反向代理、应用进程。  
用 `ss`/`curl -v`/`openssl s_client` 分层验。

---

### Q3. 如何向面试官 1 分钟讲清「输入 URL 到页面」？

DNS → TCP → TLS → HTTP → 渲染；加速靠 CDN、缓存、H2/H3、减 RTT。详见 [[07-输入URL全过程]]。

---

### Q4. 直播 / 通话为什么倾向 UDP？

可接受丢包，更怕延迟；用应用层纠错/自适应码率。可靠文件传输仍 TCP/QUIC。
