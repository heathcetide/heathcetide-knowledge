# 07 · 输入系统与动画

---

## 面试 / 自测题

### Q1. 为什么要用 InputMap 而不是硬编码键码？

`project.godot` 里定义动作：`jump`、`move_left`、`attack`…

```gdscript
if Input.is_action_just_pressed("jump"):
    ...
var axis = Input.get_axis("move_left", "move_right")
```

好处：改键、手柄映射、多套方案（P1/P2）不用改逻辑代码。

双人同屏：做 `p1_jump` / `p2_jump` 两套动作，角色只读自己的 seat。

---

### Q2. just_pressed、pressed、echo 区别？

| API | 含义 |
| --- | --- |
| `is_action_pressed` | 按住为真 |
| `is_action_just_pressed` | 刚按下那一帧 |
| `is_action_just_released` | 刚松开 |
| 事件 `echo` | 系统重复键 |

攻击、跳跃用 `just_pressed`；移动用 `pressed` / `get_axis`。

---

### Q3. AnimationPlayer vs AnimatedSprite2D vs Tween？

| 工具 | 适合 |
| --- | --- |
| `AnimatedSprite2D` | 帧动画（精灵表） |
| `AnimationPlayer` | 多轨道：位置、切换精灵、调用方法、音效轨 |
| `AnimationTree` | 混合、状态机（复杂角色） |
| `Tween` | 一次性补间：UI 弹出、淡入淡出 |

复杂角色常用：**AnimationPlayer + 状态枚举（Idle/Run/Attack）**。

---

### Q4. 动画如何「打伤害点」？

AnimationPlayer 加 **Call Method Track** 或 **Audio Track**：

- 在挥刀某一帧调用 `enable_hitbox()`  
- 结束帧 `disable_hitbox()`  

比纯计时更跟手，改动画不改代码 Timing。

---

### Q5. Godot 4 动画库（AnimationLibrary）要注意什么？

动画可放在库里再挂到 AnimationPlayer。  
从旧工程 / 资源还原工具迁过来时，库引用丢失会导致「有 Player 没动画」。

导出前在编辑器打开角色场景，确认动画列表非空；必要时用工具脚本批量 resave。

---

### Q6. Tween 基本写法？

```gdscript
var t = create_tween()
t.set_ease(Tween.EASE_OUT).set_trans(Tween.TRANS_CUBIC)
t.tween_property(self, "modulate:a", 0.0, 0.3)
t.tween_callback(queue_free)
```

UI、飘字、镜头轻微震动很适合 Tween。

## 易错点

- UI 焦点吃掉按键：游戏玩法输入与菜单抢焦点。  
- 动画未循环却在代码里空等 `animation_finished`。  
- 缩放/翻转角色时攻击盒方向没跟着 `scale.x` / `flip_h` 更新。
