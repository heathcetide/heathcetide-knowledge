# 07 · 插件与分页

## 面试题

### Q1. 插件运行原理？如何编写？能否嵌套？

MyBatis 插件基于 **拦截器 + JDK 动态代理链**，可拦截四大对象：

- `Executor`  
- `ParameterHandler`  
- `ResultSetHandler`  
- `StatementHandler`  

**原理：**

1. `@Intercepts` + `@Signature` 声明拦截类/方法/参数  
2. 创建对象时，`Plugin.wrap` 若匹配则生成代理  
3. 多个插件 **嵌套代理**（责任链）：先注册的在外层或按顺序包裹，形成嵌套调用  
4. `intercept(Invocation)` 里可改 SQL、改参数，再 `invocation.proceed()`  

**编写步骤：** 实现 `Interceptor` → 注解签名 → `plugin(target)` 通常 `Plugin.wrap` → `setProperties` → 配置里 `<plugins>` 注册。

**能嵌套：** 多个插件层层代理，要注意顺序与重复改写 SQL。

### Q2. MyBatis 如何分页？分页插件原理？大数据分页优化？

**原生：** SQL 写 `LIMIT`；或 `RowBounds`（逻辑分页：查出再切，大数据不行）。

**PageHelper 等插件原理（典型）：**

1. 拦截 `Executor`/`StatementHandler`  
2. ThreadLocal 取分页参数  
3. 先执行 `count`（或子查询 count）  
4. 改写原 SQL，追加 `LIMIT offset,size`（方言适配）  
5. 查询后封装 `Page` 总条数  

**大数据 / 深分页：**

- 避免巨大 OFFSET：改 seek（`WHERE id > ? LIMIT n`）  
- 覆盖索引 + 延迟关联  
- 不要用逻辑 RowBounds 扫全表  
- 详见 [[../MySQL/08-SQL语法与调优]]
