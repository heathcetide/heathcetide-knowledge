# 09 · 类型转换、连接池、日志与多数据源

---

## 面试题

### Q1. 数据库类型和 Java 类型如何转换？

**TypeHandler：**

- 设参：`setParameter` 把 Java → JDBC  
- 取值：`getResult` 把 JDBC → Java  
- 内置：基本类型、日期、`BigDecimal`、Enum 等  
- 自定义：实现 `TypeHandler` 或继承 `BaseTypeHandler`，注册到 config 或 `@MappedTypes`  

JSON 字段、枚举 code、加密列常用自定义 TypeHandler。

---

### Q2. 自带连接池了解过吗？

MyBatis 内置 **PooledDataSource**（还有 Unpooled）：

- 维护 idle/active 连接池  
- 可配最大活跃、空闲、超时检测  

生产多用 **HikariCP / Druid**，通过 `environment.dataSource` 或 Spring Boot 配置接入，而不是强依赖内置池。

---

### Q3. 日志打印如何实现？如何调试运行 SQL？错误排查技巧？

- 适配：`slf4j` / `log4j2` / `stdout_logging` 等  
- 把 Mapper 包或具体类日志调到 **DEBUG**，打印 SQL、参数、行数  
- 可配 `logImpl`  
- 开发可用 p6spy、datasource-proxy 打印完整带参 SQL  
- 排查：先看最终 SQL → 拷到客户端 EXPLAIN → 看映射是否空字段（列名驼峰）→ 看插件是否改写  

---

### Q4. 如何支持多数据源？如何处理读写分离？

**多数据源：**

1. 多个 `SqlSessionFactory` + 不同 DataSource  
2. 动态数据源：`AbstractRoutingDataSource` + ThreadLocal 决定 key  
3. 中间件分片（ShardingSphere）对应用暴露单数据源  

**读写分离：**

- 路由：写操作 → master，读 → slave（注意事务内读要走主）  
- 可用动态数据源注解 `@Master/@Slave`，或依赖代理中间件  
- MyBatis 本身不内置读写分离，是 **数据源路由问题**
