## 面试题

### Q1. struct 是否可以比较？

- 字段均可比较（无 slice/map/func 等）→ struct **可用 `==`**  
- 含不可比较字段 → 不能 `==`，可用 `reflect.DeepEqual`  

可比较 struct 能作 map key。

### Q2. tag 的用处？

结构体字段标签：元数据字符串，反射读取。

```go
type User struct {
    Name string `json:"name" db:"user_name"`
}
```

用途：JSON/XML 序列化、ORM 列名、校验、swagger 等。**语言不解释 tag**，库解释。

### Q3. switch 如何强制执行下一个 case？

Go **默认不 fallthrough**。需要时写：

```go
switch x {
case 1:
    fmt.Println(1)
    fallthrough  // 强制进入下一 case 体（不判断下一条件）
case 2:
    fmt.Println(2)
}
```

`fallthrough` 只能落到下一个 case 正文。

### Q4. make 和 new 区别？

| | `new(T)` | `make(T)` |
| --- | --- | --- |
| 返回 | `*T`，指向零值 | `T` 本身（slice/map/chan） |
| 用途 | 任意类型分配 | **仅** slice、map、channel |
| 初始化 | 仅零值 | 初始化内部结构可用 |

```go
p := new(int)           // *int
s := make([]int, 0, 10) // []int
```

### Q5. Java 和 Go 的区别？（常考）

| 维度 | Java | Go |
| --- | --- | --- |
| 范式 | OOP 为主，类继承 | 组合 + 接口，无类继承 |
| 错误 | 异常 | `error` + 少用 panic |
| 并发 | Thread / JUC | goroutine + channel |
| 泛型 | 成熟已久 | 1.18+ 才有 |
| 运行 | JVM 字节码 | 编译成本地代码，GC |
| 依赖 | 包管理演进长 | module 简洁 |
| 可见性 | public/private… | 大小写跨包 |
| 继承 | extends | 嵌入（embedding） |

口述抓：**简洁、组合优于继承、CSP 并发、显式错误处理**。
