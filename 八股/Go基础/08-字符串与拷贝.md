# 08 · 字符串与拷贝

---

## 面试题

### Q1. 深拷贝和浅拷贝？

- **浅拷贝：** 拷贝顶层结构，内部指针/切片/map 仍共享  
  - 例：`b := a`（slice）、struct 含指针字段赋值  
- **深拷贝：** 递归复制，互不影响  
  - 例：`copy` 到新 slice；手动复制字段；`gob`/JSON 往返（重）  

string 赋值是拷贝「头」（ptr+len），底层只读数据共享（不可变，安全）。

---

### Q2. 字符串转 `[]byte` 会发生拷贝吗？

**会。** `[]byte(s)` / `string(b)` 一般**分配并拷贝**，因 string 不可变、[]byte 可变，必须断开共享（除非编译器证明不会修改等优化，面试以「会发生拷贝」为主）。

---

### Q3. 字符串与 `[]byte` 零拷贝转换？

标准库不鼓励。旧写法用 `unsafe`：

```go
func StringToBytes(s string) []byte {
    return unsafe.Slice(unsafe.StringData(s), len(s))
}
func BytesToString(b []byte) string {
    return unsafe.String(unsafe.SliceData(b), len(b))
}
```

**风险：** 改 []byte 会破坏 string 不可变假设 → 诡异 bug。仅只读、生命周期可控时用。Go 1.22+ 有更安全的 unsafe 辅助；优先正常转换。

---

### Q4. 如何翻转含中文、数字、英文的字符串？

按 **rune** 翻转，不能按 byte（会拆坏 UTF-8）：

```go
func reverse(s string) string {
    r := []rune(s)
    for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
        r[i], r[j] = r[j], r[i]
    }
    return string(r)
}
```

涉及组合字符/emoji 时可能还需规范化（进阶）。

---

### Q5. 自定义类型切片 ↔ 字节切片？

同构、连续内存时可用 `unsafe` 或编码协议（gob/json/binary）。面试常答：

1. **序列化：** `encoding/binary`、protobuf（推荐跨语言）  
2. **unsafe 转换：** 要求元素无指针、了解对齐与大小，极危险  

简单数值切片可用循环或 `binary` 写入 buffer。

---

### Q6. 字符串拼接怎么写才高效？

| 方式 | 评价 |
| --- | --- |
| `+` 循环拼 | 多次分配，热路径差 |
| `fmt.Sprintf` | 方便，有解析开销 |
| `strings.Builder` | **推荐**，可 `Grow` |
| `bytes.Buffer` | 类似，偏 []byte |
| `strings.Join` | 已知片段时很好 |

```go
var b strings.Builder
b.Grow(n)
b.WriteString("a")
b.WriteString("b")
s := b.String()
```

---

### Q7. `string` 在 Go 里是不可变的吗？和 Java 比？

是：**不可变字节序列**（UTF-8）。改内容只能造新 string。  
与 Java `String` 类似（不可变）；Go 无独立 `StringBuilder` 类型名，用 `strings.Builder`。  
`len(s)` 是**字节长度**，不是字符数；字符数用 `utf8.RuneCountInString` 或转 `[]rune`。

---

### Q8. 如何高效判断前缀/包含？注意大小写？

- `strings.HasPrefix` / `HasSuffix` / `Contains`  
- 大小写不敏感：先 `strings.EqualFold` 或统一 `ToLower`（注意 Unicode 细节）  
- 大量匹配：`strings.Replacer`、正则（`regexp` 别在热路径乱编译，要 `MustCompile` 复用）  

---

### Q9. rune、byte、字符串下标 `s[i]` 分别是什么？

- `s[i]` → **byte**（uint8），不是字符  
- `for i, r := range s` → `r` 是 **rune**（Unicode code point），`i` 是字节下标  
- 截取中文必须按 rune 或用 `utf8` 解码，乱切 byte 会得到非法 UTF-8  

见 [[01-变量常量与基础类型]]。
