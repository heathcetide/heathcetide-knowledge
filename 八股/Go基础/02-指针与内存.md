## 面试题

### Q1. 指针的意义是什么？

指针保存**变量的地址**，用于：

1. 函数中修改调用方变量（避免只改副本）  
2. 避免大结构体拷贝  
3. 表达「可有可无」（nil）  
4. 形成数据结构（链表、树）  

Go **限制指针运算**（安全），没有 C 那套随意 `p+1`（除非 `unsafe`）。

---

### Q2. 通过指针 `p` 访问成员 `title` 有哪几种方式？

```go
type Book struct{ Title string }
p := &Book{Title: "Go"}

(*p).Title  // 显式解引用
p.Title     // 语法糖：选择器自动解引用
```

**对象选择器自动解引用：** 写 `p.Title` 即可，编译器变成 `(*p).Title`。反过来，值调用指针接收者方法时也可能自动取址（满足可寻址等条件）。

---

### Q3. 局部变量分配在栈还是堆？

**由编译器逃逸分析决定，不是语法规定。**

- 不逃逸 → 倾向**栈**  
- 逃逸到堆（返回指针、被闭包引用、赋给全局/interface 等）→ **堆**，由 GC 回收  

可用 `go build -gcflags="-m"` 查看逃逸。

---

### Q4. 函数返回局部变量的指针是否安全？

**安全。** Go 会把该变量分配到**堆**上（逃逸），生命周期延长到没有引用为止。不像 C 返回栈地址悬空。

```go
func f() *int {
    x := 1
    return &x // OK，x 逃逸到堆
}
```

---

### Q5. 不分配内存的指针能用吗？

可以有 **nil 指针**（不指向有效内存）。  
对 nil 解引用 → **panic**。  
可先判断 `if p != nil`。  
`new(T)` 会分配并返回非 nil（指向零值）。

---

### Q6. 所有 T 都有 `*T` 吗？

对每个类型 `T`，都存在指针类型 `*T`。  
接口类型也有 `*I`，但少见；通常讨论的是具名字类型的指针。

---

### Q7. 非接口类型 T 能否调用 `*T` 的方法？反过来呢？（方法集）

**方法集规则（重要）：**

| 调用方 | 可用方法 |
| --- | --- |
| 类型 `T` 的值 | 只有 **值接收者** `(T)` 的方法 |
| 类型 `*T` | 值接收者 + **指针接收者** `(*T)` |

因此：

- **值 `T` 不能直接调用只定义在 `*T` 上的方法**（会编译错误）；但若 `T` 可寻址，`t.Method()` 会自动变成 `(&t).Method()`  
- **`*T` 可以调用 `T` 的值接收者方法**（自动解引用）  

接口赋值时更严：只有方法集匹配的类型才能赋给接口（`T` 不能赋给需要指针方法的接口）。

---

### Q8. 有没有 this 指针？

**没有 this/self 关键字。** 方法接收者自己命名：

```go
func (u *User) Name() string { return u.name }
```

习惯叫 `u`/`s`/`r`，不是语言强制。

---

### Q9. 指针运算有哪些？

安全 Go：**只有取址 `&`、解引用 `*`、比较（含 nil）**。  
不能 `p++`、不能指针加减（那是 `unsafe.Pointer` / `uintptr` 的领域，面试说「默认不做指针运算」）。

---

### Q10. 如何访问私有成员？

在Go语言中，以小写字母开头的标识符是私有成员，私有成员的字段，方法，函数也遵循这套可见性规则，包外无法访问这些私有成员，如果需要访问私有成员，可以使用如下方法：
1. 在同一个包内可以直接访问小写字母开头的私有成员
2. 在其他包中使用的话，封装公开的方法来间接访问
3. 使用反射进行Go的封装机制访问和修改私有字段
4. 使用unsafe进行访问私有字段
